# HorseRacingPrompts

競馬で集めた情報から「2連複」を当てることを目的とした、Claude Code 上で動く自己改善型AIシステムです。

## 目的

**2連複を的中させ、回収率をプラスにすること。** それによって「競馬で儲ける」という最終目的を達成します。

## 方針

```
2連複になりそうな組み合わせを3点ピックアップする
    ↓
オッズ比率の関係から、その3点はほぼ当たる
    ↓
ほぼ当たる ＝ 回収率も良くなる
    ↓
競馬で儲けるという目的を達成できる
```

単に高オッズを狙って一発を当てにいくのではなく、**「ほぼ外さない3点」を選び抜くこと**を最優先とします。的中率を犠牲にしてオッズ妙味を追うより、的中率を高い水準に保ったまま組み合わせのオッズ比率を活かす方が、長期的な回収率を安定してプラスにできる、という理屈に基づいています。
