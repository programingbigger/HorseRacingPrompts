# HorseRacingPrompts (馬券的中プロンプト集)

AI（ChatGPT, Claude, Gemini等）を活用して競馬の予想精度を向上させ、的中を目指すためのプロンプト管理リポジトリです。

## 概要

このプロジェクトは、競馬データの分析、展開予想、馬券構成の最適化など、競馬予想の各プロセスに特化したプロンプトを体系的にまとめることを目的としています。

## ディレクトリ構成

- `prompts/`: 各種分析・予想用プロンプトテンプレート
  - `race_analysis/`: レース傾向・展開予想
  - `pedigree/`: 血統分析
  - `paddock/`: パドック・馬体分析
  - `betting_strategy/`: 買い目構築・資金管理
- `data_templates/`: プロンプトに入力するためのデータ整形フォーマット
- `docs/`: 競馬予想におけるAI活用のノウハウ

## 使い方

1. `prompts/` 内の目的のプロンプトを選択します。
2. 競馬新聞やネット上のデータ（JRA公式サイト、netkeiba等）から必要な情報をコピーします。
3. プロンプトの `[ ]` で囲まれた部分にデータを流し込み、AIに入力してください。
