# HorseRacingPrompts

単勝馬券の回収率をプラスにすることを目的とした、Claude Code 上で動く自己改善型AIシステムです。

**予想 → 結果検証 → 自己フィードバック → 判断軸の改善** のサイクルを自動化し、長期的な回収率向上を目指します。

## 基本方針

```
回収率プラス = 的中率 × オッズ > 1.0
```

単純に当てにいくのではなく、**「過小評価されている馬（オッズ妙味がある馬）」を見つける**ことを最優先とします。

## 使い方

Claude Code 上で、netkeiba の出走表 URL を貼るだけです。

```
https://race.netkeiba.com/race/shutuba.html?race_id=202605021211
```

`keiba-tansho-picker` エージェントが自動起動し、情報収集から推奨馬の提示まで行います。

## コンポーネント

### `keiba-tansho-picker` エージェント

netkeiba の URL を受け取り、情報収集〜期待値計算〜推奨馬の提示を自動で行います。

- **情報収集：** `keiba-joho-shushu` スキルを呼び出してnetkeibaを巡回
- **分析：** 収集データを基に推定的中率・期待値を算出
- **出力：** 推奨単勝馬と選定理由をチャットで提示

### `keiba-joho-shushu` スキル

Claude in Chrome でnetkeibaを巡回し、レース情報をマークダウンファイルとして保存します。

収集するデータ：
- 出走馬一覧（馬番・馬名・騎手・斤量）
- リアルタイムオッズ・馬体重
- 過去レース傾向（枠順・脚質・人気別成績）
- 各馬の血統・コース成績

## 現状と今後（v2）

現状は情報収集と予想が同一ファイルに混在しています。v2 では以下のように分離し、フィードバックループを確立します。

| フォルダ | 内容 |
|----------|------|
| `data/` | 純粋な情報素材（AIの判断なし） |
| `predictions/` | AIの予想・推奨（新設） |
| `feedback/` | レース結果との照合・自己反省（新設） |

詳細は [SPEC.md](SPEC.md) を参照してください。
