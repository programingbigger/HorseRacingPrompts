# ステップ 2：コーナー通過順位の収集

## 対象

ステップ 1 で特定した各参照R（最大3R）のレース結果ページ。

---

## 収集URL

```
https://race.netkeiba.com/race/result.html?race_id={race_id}
```

参照Rの race_id は、対象Rの race_id の `SS`（レース番号部分、末尾2桁）をゼロ埋め2桁で変えて生成する。

例：対象 race_id=`202605030211`（11R）の場合
- 8R → `202605030208`
- 7R → `202605030207`
- 5R → `202605030205`

---

## 収集項目

上位5頭（最低1着馬は必須）について以下を取得する：

| 項目 | 内容 |
|---|---|
| 着順 | 1着〜5着 |
| 馬名 | 馬の名前 |
| 馬番 | 馬番（枠番も取得できれば合わせて記録） |
| 1角通過順位 | コーナー1角（第1コーナー） |
| 2角通過順位 | コーナー2角（第2コーナー） |
| 3角通過順位 | コーナー3角（第3コーナー） |
| 4角通過順位 | コーナー4角（第4コーナー） |

---

## 注意事項

- **短距離戦（1200m等）:** 3・4角のみの場合あり。取得できた角のみ記録し、「3・4角のみ」と明記する
- **直線コース（1000m・1200m 直線等）:** コーナーなしのため「直線コース」と明記してスキップし、その分参照Rを1R増やして補完する
- コーナー通過順位が `=` 表記（2頭同順）の場合はそのまま記録する
- 1着馬のデータは必須。取得不可の場合はそのRをスキップする

---

## 情報取得の方法

```
① Chrome in Claude でレース結果ページを開く（推奨・優先）
      ↓ うまくいかない場合
② WebFetch で直接取得を試みる（race_id を末尾に付けたURL）
      ↓ それでも取得できない場合
③ 「取得不可」と明記してスキップし、次のRへ進む（ループ禁止）
```

---

## レース結果ページでの確認箇所

netkeiba のレース結果ページでは「コーナー」欄に各コーナー通過順位が記載されている。
表記例：`1-1-1-1`（1角・2角・3角・4角すべて1番手）

取得する際は、この順位欄の値をそのまま記録すること。
