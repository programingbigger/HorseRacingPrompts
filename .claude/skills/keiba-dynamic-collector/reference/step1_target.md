# ステップ 1：対象R・参照Rの特定

## 手順

1. 入力URLから `race_id` を取得する
   - 例：`race_id=202605030211`
2. `race_id` をパースして以下を特定する

### race_id フォーマット

```
YYYY PP QQ RR SS
```

| 部分 | 桁数 | 内容 | 例 |
|---|---|---|---|
| YYYY | 4 | 年 | 2026 |
| PP | 2 | 競馬場コード | 05（東京） |
| QQ | 2 | 開催回数 | 03（第3回） |
| RR | 2 | 開催日目 | 02（2日目） |
| SS | 2 | レース番号 | 11（11R） |

### 競馬場コード一覧

| コード | 競馬場 |
|---|---|
| 01 | 札幌 |
| 02 | 函館 |
| 03 | 福島 |
| 04 | 新潟 |
| 05 | 東京 |
| 06 | 中山 |
| 07 | 中京 |
| 08 | 京都 |
| 09 | 阪神 |
| 10 | 小倉 |

3. 対象Rの**馬場種別**（芝 or ダート）を出走表から確認する
   - 出走表URL（shutuba.html）をそのまま参照するか、Chrome in Claude で開いて確認する
4. 同日・同競馬場・**同馬場種別**の参照Rを以下のルールで特定する

---

## 参照Rの決定ルール

### 通常（4R以降）

対象Nから1〜3R前（同馬場のみ）を参照する。

- N-1, N-2, N-3 の順に確認していく
- 各Rの馬場種別はレース結果ページまたはChrome in Claude で確認する
- 異なる馬場（芝⇔ダート）はスキップしてカウントしない
- 3R分に満たない場合は取得できた分だけで判断する

#### 例

対象：9R（芝）
- 8R → 芝 → 参照対象
- 7R → 芝 → 参照対象
- 6R → ダート → **除外**
- 5R → 芝 → 参照対象
→ 参照：8R, 7R, 5R

---

### 例外：1〜3Rの場合

#### 土曜日

| 対象R | 参照R |
|---|---|
| 1R | 参照なし（収集対象外） |
| 2R | 1R のみ（同馬場の場合） |
| 3R | 1R, 2R（同馬場のみ） |

#### 日曜日

| 対象R | 参照R |
|---|---|
| 1R | 前日（土曜日）の最終3R分（同競馬場・同馬場種別） |
| 2R | 本日1R + 必要に応じ前日分で補完 |
| 3R | 本日1R, 2R（同馬場のみ） |

**前日データの race_id の生成方法：**
前日（土曜日）は `RR`（開催日目）を `01` にして、`SS` を該当Rに変更する。

例：日曜（RR=02）の1Rを予想 → 前日最終3Rは RR=01 の最終3R

---

## 曜日判定

race_id の日付情報だけでは曜日が特定できない場合は、開催日目（RR）で代用する。

- `RR=01`：土曜日（開催1日目）
- `RR=02`：日曜日（開催2日目）
- `RR=03` 以降：連続開催（平日開催等）

---

## 情報取得の方法

```
① Chrome in Claude（mcp__claude-in-chrome__navigate 等）でページを開く（推奨・優先）
      ↓ うまくいかない場合
② WebFetch で直接取得を試みる
      ↓ それでも取得できない場合
③ 「取得不可」と明記してスキップし、次の処理へ進む
```
