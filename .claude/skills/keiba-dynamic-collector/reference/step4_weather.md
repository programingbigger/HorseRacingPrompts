# ステップ 4：天気・馬場発表の収集

## 収集内容

- 現在の天気（晴/曇/雨 など）
- 芝馬場状態（良/稍重/重/不良）
- ダート馬場状態（良/稍重/重/不良）

---

## 収集方法

### ① tenki.jp から取得（優先）

競馬場コードに対応した tenki.jp の URL を [tenki_urls.md](tenki_urls.md) から引く。

```
① Chrome in Claude でページを開く（推奨・優先）
      ↓ うまくいかない場合
② WebFetch で直接取得
      ↓ それでも取得できない場合
③ 「取得不可」と明記してスキップし、次の処理へ進む
```

### ② JRA公式からの馬場状態取得（補完用）

tenki.jp が取得できない、または馬場状態（良/稍重等）が不明な場合は、JRA公式サイトから取得する。

馬場状態は通常レース前に発表されるため、開催日の午前中以降に取得すること。

```
https://www.jra.go.jp/keiba/baba/index.html
```

---

## 出力形式

```
## 天気・馬場発表
- 天気：曇り
- 芝：良
- ダ：稍重
- 情報元：tenki.jp（取得日時：2026-06-08 10:30）
```

馬場状態が未発表の場合は「未発表（発表後に更新要）」と記載する。

---

## 注意

- tenki.jp と JRA公式で情報が異なる場合は **JRA公式を優先** する
- 天気は取得時点のもの。レース時刻と大きく異なる場合は注記する
