# ステップ 5：調教師情報の収集

全レースの調教師ごとに以下を収集する。

## 収集内容

- 調教師のプロフィール（所属厩舎・経歴など）
- 今回の競馬場・距離・コース条件での勝率・連対率
- 得意な馬質・ローテーション傾向（長期休養明けの仕上げが上手いか、など）
- 出走馬に対する直近のコメント・調教評価（web 検索で補完）

web 検索クエリ例：
```
"{調教師名} 調教師 {馬名} 調教 2026"
"{調教師名} 調教師 近況 コメント"
```

## 情報取得の方法

```
URL：https://db.netkeiba.com/trainer/{trainer_id}/

① Chrome in Claude（mcp__claude-in-chrome__navigate 等）でページを開く（推奨・優先）
      ↓ うまくいかない場合
② WebFetch で直接取得を試みる
      ↓ それでも取得できない場合
③ web 検索（過去1年フィルター）で補完を試みる
      ↓ それでも取得できない場合
④ 「取得不可」と明記してスキップし、次の処理へ進む
```

## 調教師 ID の取得方法

URL 末尾の数値をそのまま ID として使用する。

```
例）https://db.netkeiba.com/trainer/01114/ → ID は 01114
```

## 保存先

```
Info/static/調教師/{調教師ID}.md    例：01114.md
```

## ファイル管理ルール

- 既存ファイルがある場合：ID で検索し上書き（全量上書き）
- 存在しない場合：新規作成
