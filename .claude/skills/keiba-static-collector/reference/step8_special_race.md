# ステップ 8：対象レース専用フォルダの作成（特定レースモードのみ）

特定レースが指定された場合、対象レース名のフォルダを作成し、以下の 3 ファイルを作成する。

## 作成ファイル

```
Info/static/その他/{レース名}/
├── 過去傾向.md          ← 過去10年の勝ち馬の血統・脚質・ローテーション傾向
├── 好走馬パターン.md    ← 好走条件（枠・馬場・距離方向など）の共通点
└── 今年の出走馬分析.md  ← 収集した馬情報MDと好走パターンの突合サマリー
```

## 情報取得の方法

```
URL：https://race.netkeiba.com/race/past10.html?race_id={RID}（+ web 検索）

① Chrome in Claude（mcp__claude-in-chrome__navigate 等）でページを開く（推奨・優先）
      ↓ うまくいかない場合
② WebFetch で直接取得を試みる
      ↓ それでも取得できない場合
③ web 検索（過去1年フィルター）で補完を試みる
      ↓ それでも取得できない場合
④ 「取得不可」と明記してスキップし、次の処理へ進む
```
