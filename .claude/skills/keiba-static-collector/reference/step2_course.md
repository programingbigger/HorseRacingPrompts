# ステップ 2：競馬場情報の収集（開催週のコース状態）

## 収集内容

対象競馬場ごとに以下を収集する：

- 今回が何週目の開催か（開幕週 or 後半週）
- 馬場の傷み具合・内外の有利不利
- 芝・ダートそれぞれの馬場コンディション傾向

## 馬場の継続使用に注意

「東京1日目」でも前週からの続きの可能性がある。
開催カレンダーを確認し、実態（何週目相当か）を必ず記録すること。

```
例：5/31 が東京12日目 → 6/5 が東京1日目でも馬場は継続使用
```

## 情報取得の方法

```
① Chrome in Claude（mcp__claude-in-chrome__navigate 等）で競馬場ページを開く（推奨・優先）
      ↓ うまくいかない場合
② WebFetch または web 検索で補完を試みる
      ↓ それでも取得できない場合
③ 「取得不可」と明記してスキップし、次の処理へ進む
```

## 保存先

```
Info/static/競馬場/中央/{競馬場名}.md    例：東京.md
Info/static/競馬場/地方/{競馬場名}.md    例：大井.md
```

## ファイル管理ルール

- 存在しない場合：新規作成
- 既存ファイルがある場合：ファイル内の `更新日` を確認
  - **1週間以内**：既存ファイルに最新情報を追記（週ごとの履歴として列挙）
  - **1週間超**：全量上書き（再収集）
