# ステップ 3：馬情報の収集（⑧⑪⑫⑬）

全レースの出走馬ごとに以下を収集する。

## ⑧ 馬体重のベスト値

- 過去の好走時（3着以内）の体重一覧
- 直近の体重トレンドと好走時体重との比較

## ⑪ 距離・間隔適性

- 今回距離での過去成績（距離短縮 or 延長の方向性）
- 休養明けの実績（何週間の間隔で走ったレースの成績）

## ⑫ 前走ペース・展開の恩恵

- 前走の展開（ハイペース消耗敗戦か、スローで脚を使えなかったか）
- 次走での巻き返し期待の有無

## ⑬ 脚質（逃げ・差し特性）

直近5レース（5レースに満たない場合は取得できた全レース）の通過順位を確認し、各レースの脚質を判定する。

### 判定基準（1・2コーナー通過順位を基準とする）

| 脚質ラベル | 通過順位の目安 |
|---|---|
| 逃げ | 1番手 |
| 先行 | 2〜5番手 |
| 差し | 6番手〜（概ね中団後方） |
| 追込 | 後方（出走頭数の後ろ1/3以降） |

### 収集する情報

- 各レースごとの脚質ラベル（上記判定基準で判定）
- 直近5レースの脚質一覧（レース名・日付・脚質・着順）
- 総合的な脚質傾向（例：「主に先行〜差し」「逃げ多用」など一言でまとめる）

### 取得方法

馬の過去成績ページ（`https://db.netkeiba.com/horse/{horse_id}`）の成績テーブルで「通過順」列を参照する。\
通過順は「コーナー通過順位」がスラッシュ区切りで記載されている（例：`3-3-2-1` → 最初のコーナーで3番手）。\
直近5レース分を新しい順に取得し、判定基準に沿って脚質ラベルを付ける。

## 情報取得の方法

```
URL：https://db.netkeiba.com/horse/{horse_id}

① Chrome in Claude（mcp__claude-in-chrome__navigate 等）でページを開く（推奨・優先）
      ↓ うまくいかない場合
② WebFetch で直接取得を試みる
      ↓ それでも取得できない場合
③ 「取得不可」と明記してスキップし、次の処理へ進む
```

## 馬 ID の取得方法

URL 末尾の数値をそのまま ID として使用する。

```
例）https://db.netkeiba.com/horse/2022102790 → ID は 2022102790
```

## 保存先

```
Info/static/馬情報/{馬ID}.md    例：2022102790.md
```

## ファイル管理ルール

- 既存ファイルがある場合：ID で検索し上書き
- 存在しない場合：新規作成
