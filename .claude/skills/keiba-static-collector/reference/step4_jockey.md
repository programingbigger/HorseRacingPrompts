# ステップ 4：騎手情報の収集（⑥）

全レースの騎手ごとに以下を収集する。

## ⑥ 騎手の当コース成績

- 今回の競馬場×距離×芝ダートでの勝率・連対率
- 乗り替わりの有無と方向（昇格 or 降格の評価）

## 騎手の性格・スキャンダル情報（web 検索で取得・必須）

**出走ページからは取得不可のため、必ず web 検索を使うこと。**

収集内容：
- 騎手の騎乗スタイル・性格（積極的か慎重か、追い方の特徴など）
- 直近のスキャンダル・不祥事・停止処分の有無
- 現在のモチベーション・体調・話題性（インタビュー記事等）

web 検索クエリ例：
```
"{騎手名} 騎手 スキャンダル 2026"
"{騎手名} 騎手 性格 騎乗スタイル"
"{騎手名} 騎手 近況 インタビュー"
```

## 情報取得の方法

```
URL：https://db.netkeiba.com/jockey/result/recent/{jockey_id}/

① Chrome in Claude（mcp__claude-in-chrome__navigate 等）でページを開く（推奨・優先）
      ↓ うまくいかない場合
② WebFetch で直接取得を試みる
      ↓ それでも取得できない場合
③ web 検索（過去1年フィルター）で補完を試みる
      ↓ それでも取得できない場合
④ 「取得不可」と明記してスキップし、次の処理へ進む
```

## 騎手 ID の取得方法

URL 末尾の数値をそのまま ID として使用する。

```
例）https://db.netkeiba.com/jockey/result/recent/05386/ → ID は 05386
```

## 保存先

```
Info/static/騎手/{騎手ID}.md    例：05386.md
```

## ファイル管理ルール

- 既存ファイルがある場合：ID で検索し上書き
- 存在しない場合：新規作成
