# 競馬情報収集スキル

## 目的

単勝馬券の回収率をプラスにする。すなわち **期待値 = 的中率（1着確率） × オッズ** が1.0を超える馬を特定するための情報を集め、整理する。

---

## 入力

ユーザーから受け取る情報：

| 情報 | 形式 | 例 |
|---|---|---|
| 出走表URL | netkeiba の shutuba.html | `https://race.netkeiba.com/race/shutuba.html?race_id=202605021211&rf=race_submenu` |

`race_id` を URL から抽出し、以下のすべての派生 URL を構築する。

---

## ステップ 1：URLの構築

`race_id` を `{RID}` とおき、以下の URL を生成する。

```
出走表（オッズ・馬体重）: https://race.netkeiba.com/race/shutuba.html?race_id={RID}
データ分析:              https://race.netkeiba.com/race/data_top.html?race_id={RID}
過去10年の結果（重賞のみ）: https://race.netkeiba.com/race/past10.html?race_id={RID}
```

出走表ページから各馬のリンクを取得し、各馬の情報ページ URL を構築する：
```
各馬の情報: https://db.netkeiba.com/horse/{horse_id}
```

---

## ステップ 2：情報の収集

### ① 過去のレース傾向

`data_top.html` と `past10.html`（重賞の場合のみ）を取得し、以下を抽出する：

- コース特性（枠順有利不利、脚質傾向、上がり3F重要度）
- 人気別勝率・連対率
- 前走レース別成績（どの路線が強いか）
- 天候・馬場状態別成績

### ② 血統・コース適性

各馬の `db.netkeiba.com/horse/{horse_id}` から以下を抽出する：

- 父・母父の系統（ディープインパクト系、キングカメハメハ系など）
- 当該コース（競馬場・距離・芝/ダート）での成績
- 過去レース歴・獲得賞金
- 調教師・騎手

### ③ リアルタイムオッズ・馬体重

`shutuba.html` から取得する：

- 各馬の単勝オッズ（**オッズ列の「🔃更新」ボタンを1回押下してから取得すること**）
- 馬体重と増減（レース40分前に公開される。未公開の場合は「未公開」と記載）
- 馬番・枠番

---

## ステップ 3：期待値スコアの計算

各馬について以下の観点で **定性的な期待値スコア（高/中/低）** を判定する：

1. **コース適性スコア**：血統・過去成績がこのコースに合っているか
2. **レース傾向適合度**：前走路線・脚質がレース傾向データに合っているか
3. **オッズ妙味**：期待値 = 推定的中率 × 単勝オッズ　が 1.0 超か
4. **馬体重**：大幅な増減（±10kg以上）は注意フラグを立てる

**推奨馬の条件（すべて満たすこと）：**
- コース適性スコア：高
- レース傾向適合度：中以上
- 単勝オッズ：3.0倍以上（低オッズ馬は期待値が出にくい）
- 馬体重増減：±10kg未満

---

## ステップ 4：保存先フォルダとファイル名の決定

### フォルダ構成

```
{競馬場名}/
  {YYYY年MM月}/
    {コース種別}_{距離}m_{レース名}.md
```

**例：**
```
東京競馬場/
  2026年05月/
    芝_2400m_日本ダービー.md
```

- `{競馬場名}` は出走表から取得（例：東京競馬場、阪神競馬場）
- `{YYYY年MM月}` は race_id の先頭6桁から導出（例：202605 → 2026年05月）
- `{コース種別}` は **必須**（芝 or ダート）
- `{距離}` は m 単位（例：2400）
- `{レース名}` は出走表から取得（例：日本ダービー、1回東京11R）

### 既存ファイルがある場合

同名ファイルが既に存在する場合は、**既存ファイルに追記**する（上書きしない）。
ファイル末尾に `---` 区切り線を入れ、新しいセクションを追加する。

## 注意事項

- netkeibaのページはJavaScript描画が多いため、取得できない場合は `mcp__playwright__*` や `mcp__Claude_in_Chrome__*` を使ってブラウザ経由で取得する
- 重賞レースでない場合、`past10.html` は存在しないため404になる。その場合はスキップしてよい
- オッズ更新ボタンの押下はブラウザツールを使って行う。テキスト取得のみでは最新オッズが反映されない
- 馬体重はレース40分前に公開される。それ以前に実行した場合は「馬体重：公開前（レース40分前に更新してください）」と記載する
